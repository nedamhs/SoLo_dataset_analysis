# SoLo Analysis

This repository contains the code used for the technical validation and analysis of the SoLo dataset.

## Repository Structure

- `technical_validation/` — Jupyter notebooks and R scripts used for technical validation analyses.
- `requirements.txt` — Python dependencies required to run the notebooks.

## Setup

Install the required Python packages:

```bash
pip install -r requirements.txt
```

Download the SoLo dataset and update the dataset path in the notebooks to point to its local location.
